人力車 AR 明信片｜完整獨立版

使用方法
1. 解壓縮，將裡面的全部檔案與資料夾上傳到 GitHub Main，與 index.html 放在同一層。保留 assets、vendor 資料夾結構。
2. GitHub Pages 使用 main / root；網站更新後，以手機開啟 HTTPS 網址並允許相機。
3. 按「開始掃描明信片」，對準包內 print_photo.png。可列印，或用另一台螢幕顯示。請保留整張照片，避免裁切、反光。
4. 辨識照片後，拉車人邁步、人力車沿街道循環行進，兩個車輪轉動，乘客有細微頭部及手部動作。
5. 「調整模型」可暫停／繼續、調整速度、大小、方向及離卡片高度。「結束掃描」會關閉相機。照片離開鏡頭時，模型隱藏且暫停動畫。

已包含 INDEX、GLB、照片辨識檔、動畫程式及必要函式庫，不需要自行串接。
首頁與操作介面沿用前一版。這是獨立的人力車版本。
